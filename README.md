# python-calculator

A simple calculator built in Python as one of my first programming projects whilst learning the fundamentals of Python.

# Features

- Addition
- Subtraction
- Multiplication
- Division
- Power/Exponents
- Accepts decimal values
- Understands invalidity of dividing by zero
- Detects invalidity of operations
- Runs as long as the user allows it to/Programme can be stopped

# What I learnt

This mini project helped me to practice and execute the following:

- Variable data types (including int and float)
- Arithmetic & Comparison operators
- User input w/ basic input validation
- 'if', 'elif', 'else' statements
- Lists
- 'while' loops

# How to run the programme

Run using: 'python3 calculator.py'.
Then follow the prompts provided.
